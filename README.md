# Lune & Vers for Windows

- **Lune** lights the edges of your screen in the colors of the album that's playing, with a frosted-glass player and synced lyrics.
- **Vers** shows the lyrics on your desktop, one word at a time.

Both follow any app in the Windows volume flyout: Spotify, Apple Music, browsers and more. Built on GitHub Actions (`.github/workflows/build.yml`).
